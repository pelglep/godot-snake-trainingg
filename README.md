# Snake — Godot Training Project

A simple remake of **Snake** made with **Godot** and **GDScript**.

This project was created as part of my game development learning journey.
The goal was to practice grid-based movement, random spawning, score management, collisions, UI, sprite handling, and Web export.

---

The playable version is available on itch.io:

## Controls

| Action                  | Input      |
| ----------------------- | ---------- |
| Move                    | Arrow keys |
| Restart after Game Over | Space      |

---

## Features

* Grid-based movement
* Random food spawning
* Snake growth system
* Score display
* Wall collision
* Self-collision
* Game Over screen
* Restart system
* Directional snake head sprites
* Generated floor tiles
* Generated wall border
* Web export for itch.io

---

## What I learned

This project helped me practice:

* using `Vector2` for positions and movement;
* creating grid-based movement;
* handling keyboard input;
* using arrays to store snake positions;
* checking collisions by comparing positions;
* spawning food at random positions;
* preventing food from spawning on the snake;
* instantiating scenes with `preload()` and `instantiate()`;
* adding nodes with `add_child()`;
* updating UI labels;
* managing a Game Over state;
* exporting a Godot project to Web/HTML.

# Snake — Projet d’apprentissage Godot

Un remake simple de **Snake** réalisé avec **Godot** et **GDScript**.

Ce projet a été créé dans le cadre de mon apprentissage du développement de jeux vidéo.
L’objectif était de travailler le déplacement sur grille, la génération aléatoire, la gestion du score, les collisions, l’interface, les sprites et l’export Web.

## Fonctionnalités

* Déplacement sur grille
* Génération aléatoire de la nourriture

* Affichage du score

* Collision avec le corps du serpent
* Écran de Game Over

* Sprite de tête orienté selon la direction
* Génération des tuiles de sol
* Génération des murs autour du plateau

---

## Ce que j’ai appris

Ce projet m’a permis de travailler :

* l’utilisation de `Vector2` pour les positions et les déplacements ;
* la création d’un déplacement case par case ;
* la gestion des entrées clavier ;
* l’utilisation de tableaux pour stocker les positions du serpent ;
* la comparaison de positions pour gérer les collisions ;
* la génération d’une nourriture à une position aléatoire ;
* l’évitement du spawn de nourriture sur le serpent ;
* l’instanciation de scènes avec `preload()` et `instantiate()` ;
* l’ajout de nœuds avec `add_child()` ;
* la mise à jour de labels d’interface ;
* la gestion d’un état de Game Over ;
* l’export d’un projet Godot en Web/HTML.
